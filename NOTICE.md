Every skill in `skills/` was written for Tovaka Builds. ## 2. Ootto claude-content-skills (structure and ideas)
Ootto-AI/claude-content-skills is a set of 30 skills from Ootto. We did not install or ship any of those skills.

We adapted these from it:
- The skill file layout (frontmatter plus what it does, when to use, what you'll need, instructions).
- The showrunner pattern (one skill runs the others in order).
- The two pause points in content-factory: a person approves the format pick, and again before anything is posted.
- Picking the goal first, then the emotion that drives it, then the angle (pick-angle).
- Feeding winners back so later batches build on what worked (save-winners).

What is different: Ootto's factory publishes to Instagram through a connected account and runs a live comment to DM loop. Ours never publishes or sends messages; it hands drafts to the Tovaka Scheduler, where a person approves them.
